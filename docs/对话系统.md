# 对话系统

正式关卡 `main_world.tscn` 的 `HUD/BottomText` 共用底部深色对话框。商品名称、价格、说明和操作提示沿用商店的真实瞄准检测；移开准星会更新或清除说明，不需要点击。系统反馈仍使用消息优先级和原有显示时间。

剧情显示说话人、当前一句和“左键 · 继续 / 结束”。每次左键按下只推进一句，包括结束时的点击也不会挥剑。右键不推进对白；暂停时隐藏并保留阅读位置。剧情优先于商品说明，结束后恢复最新的商品 / 操作文字；多个剧情按提交顺序排队，相同来源不会重复入队。

## 首次事件

- `WorldDialogue` 连接 `ShopDialogueZone.body_entered`：首次进入时没有持有尸体 / 商品，播放店长四句原文，并提示杀两只老鼠、把尸体丢到洞里换钱。初始剑不计作持有物，钱包已有金币也不阻止指引。持物时跳过这次首次指引，之后重进不补播。
- `Hole.corpse_received` 只在本洞实际吞入尸体时发出，商品和活体不会触发。首次投尸播放洞的十一句原文；第一笔待结算价值在对白期间保留，显示“比如现在。”时调用原喷币流程。收益仍需真实拾取，后续献祭沿用两秒结算。
- 首次标记随手动存档保存；读档和开发重置不重复触发，新游戏重置标记。兼容没有 `dialogue_progress` 字段的旧存档；旧档首次体验新增对白。临时尸体、待结算金币与当前阅读句不保存。
- `main_world.gd` 在关卡启动时确保 `WorldDialogue` 存在；缺少 `ShopDialogueZone` 时，控制器会按店长、台面和货架当前摆放范围生成仅检测玩家的 Area3D。无需把运行时节点保存进场景。场景里显式配置的控制器 / 触发区会优先复用，避免重复接线或覆盖手动布局。

## 复用接口

```gdscript
# 商品、操作指引或短时系统反馈：不同来源各自维护消息。
bottom_text.set_message(&"item_description", text, BottomText.DESCRIPTION)
bottom_text.clear_message(&"item_description")

# 剧情对白：自动排队，左键逐句推进。
bottom_text.play_dialogue(&"unique_story_id", "说话人", PackedStringArray([
	"第一句。",
	"第二句。",
]))
```

`dialogue_line_changed(source, index, text)` 可用于把表现或奖励绑定到某句，`dialogue_finished(source)` 报告整段阅读结束。不要每帧重新提交剧情；普通文字可每帧更新。

对话框使用项目像素字体，缺失汉字回退到项目自带的 Noto Sans SC；无需设备安装中文字体。新手提示在剧情期间隐藏，显示商品说明时自动避让对话框。

## 验证

`tests/run_dialogue_regression.gd` 使用真实进店 Area、抓取 / 释放尸体、洞吸力和吞入、鼠标事件及落币拾取，覆盖首次条件、原文逐句显示、对白排队、左键不挥剑、描述不拦攻击、暂停、三种窗口尺寸、奖励时机、存档兼容和场景清理。测试存档和配置均在 `/tmp` 隔离目录。

初版检查：对话 77、底部文字 95、正式商店 79、正式洞 41、主世界 / 旧档 92、新手引导 59、字体 108；另在实际 Forward+ 游戏画面中检查了店长、洞和中文显示。

2026-10-15 修复：实际场景缺少 `WorldDialogue` 和 `ShopDialogueZone`，导致两段剧情均没有触发入口。现改由正式关卡启动时确保接入，并增加缺失节点自动恢复、触发范围跟随商店布局、复用已有节点及不重复接线的回归检查。首次进店按“未持物”判断，去掉原实现额外添加的零金币限制。

修复后检查通过：对话 86、正式商店 79、主世界 / 旧档 92，共 257 项。当前已运行的游戏也已补入缺失节点，保留玩家现有金币。
