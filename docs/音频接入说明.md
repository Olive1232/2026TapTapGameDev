# 音频接入说明

2026-10-12：接入用户放在 `assets/music/` 的六个 MP3，保留原文件名。

2026-10-13：将用户提供的新攻击、走路音频移至 `assets/music/攻击.mp3`、`assets/music/走路.mp3`，替换旧音效并清理 `assets/` 根目录的重复文件及导入记录；保留原播放时机、音量和循环设置。

| 素材 | 播放位置与时机 | 默认音量 |
| --- | --- | --- |
| 主菜单bgm.mp3 | `main_menu.tscn` 的 `MenuMusic` 自动循环；设置、关于页面继续播放；进入游戏后随菜单释放 | -12 dB |
| 走路.mp3 | `player.tscn` 的 `Footsteps`，玩家有移动输入、实际位移且落地时循环；停下、腾空、顶墙时停止；负重时降低播放速度 | -14 dB |
| 攻击.mp3 | 玩家剑节点的 `SwingAudio`，前摇结束进入实际挥砍时播放；冷却中的重复点击不触发 | -8 dB |
| 洞的声音.mp3 | `hole.tscn` 的 `Ambience`，循环空间环境声；参考距离 4 米，最远 20 米 | -16 dB |
| 老鼠叫声.mp3 | `monster.tscn` 的 `Voice`，仅 `monster_rat.tres` 配置；出生后随机延迟 1.5—6 秒，完整播放后间隔 8—16 秒；最远 12 米 | -12 dB |
| 烧毁的声音.mp3 | `ElementComponent` 真正烧毁宿主前触发，草、藤蔓、尸体共用；在销毁位置播完后自动释放，最远 16 米 | -12 dB |

音乐走 `Music` 总线，其他声音走 `SFX` 总线，均发送到 `Master`。总线配置为 `resources/audio/default_bus_layout.tres`，可在 Godot 音频面板调整整体音量，或在上述音频节点调整单项 `volume_db`。烧毁声的参数在 `scripts/shared/world_sound.gd`。

主菜单音乐、脚步、洞声的 `.mp3.import` 已开启 `loop`，攻击、老鼠、烧毁保持非循环。洞声约 49 秒，作为环境声连续播放。老鼠叫声约 17 秒，以随机间隔播放避免出生时同步发声；其他怪种的 `MonsterData.voice_stream` 留空。

所有游戏内音频随暂停挂起、恢复后继续；切换场景时随场景释放。烧毁声临时挂在当前场景下，宿主消失后仍能完整播放；加载已烧开的藤蔓门时不会重放音效。
