# 底部像素文字接入说明（M25）

将 `scenes/ui/bottom_text.tscn` 实例放到新地图的 `CanvasLayer` 下，命名为 `BottomText`。组件以屏幕为参照，不依赖商店、玩家坐标或地图模型；正式地图、商店试验房和机关试验场已接入。

## 提供与清除文字

```gdscript
@onready var bottom_text: BottomText = $HUD/BottomText

# 持续指引：0 秒代表持续到主动更新 / 清除。
bottom_text.set_message(&"level_guidance", "将尸体投到高处平台。", BottomText.GUIDANCE)

# 道具描述：由道具检测来源提供，看向别处时只清除这个来源。
bottom_text.set_message(&"item_description", "镜子：尸体入洞价值 ×2。", BottomText.DESCRIPTION)
bottom_text.clear_message(&"item_description")

# 临时反馈：覆盖低优先级内容，结束后恢复当前描述或指引。
bottom_text.set_message(&"platform_feedback", "升降门已开启。", BottomText.FEEDBACK, 3.0)

# 未来对白可以使用独立来源与更高优先级；此调用只显示文字。
bottom_text.set_message(&"story_dialogue", "对白内容", 30)
bottom_text.clear_message(&"story_dialogue")
```

每个来源使用固定且独立的 `StringName`，只更新 / 清除自己的消息。`clear_all()` 用于明确要清空整个显示区域的情况。不要由每个对象随意调用它，以免清掉其他来源的内容。

同优先级最新更新的消息优先；重复提交相同的持续文本不抢占顺序。定时消息按游戏时间计时，包括暂时被更高优先级覆盖的消息；再次提交定时消息会重新计时。暂停隐藏显示并冻结时长，恢复后继续，场景退出随组件销毁全部消息。

## 商品与现有提示

商店的 `get_context_text()` 提供名称、当前价格 / 等级、`ShopItemData.description` 及操作。看向 3.5 米内商品或货架、朝向误差不超过 20°且世界碰撞不遮挡时显示；持有商品时继续显示描述与台面 / 放置操作。看向别处恢复指引；售罄货架保留已售罄 / 满级说明。

地图将 `guidance`、`shop_description`、`shop_feedback` 分别提交到组件。商店自己的反馈计时沿用约 3 秒；忙碌时持续提供工作提示。旧地图的 `Hint` / `ShopMessage` 已移除，迁移地图时直接带上新实例与这些调用。

## 显示参数

默认白字黑色描边，24px，自动换行；最大宽度 1120、左右留边 32、底边距 28，可在 Inspector 调整。高度随内容增减并向上扩展，最后一行始终保留底边距。内容应保持简短，长篇剧情按对白段落提供。

底部文字使用 `resources/ui/pixel_font.tres`，字体与许可见 `assets/fonts/README.md`。所有控件忽略鼠标输入。M26 的对白推进、视角锁定与移动 / 交互控制仍需单独实现，M25 只负责文字呈现，不进入存档。
